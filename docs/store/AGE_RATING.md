# Age Rating & Content Questionnaire Guide — AURA GAY 18+

## 1. Google Play IARC Questionnaire Responses
When completing the IARC (International Age Rating Coalition) questionnaire in Google Play Console:

| Question | Answer | Notes |
| :--- | :--- | :--- |
| **Category of App** | Social Network / Dating | User interaction, matchmaking, messaging |
| **Violence** | No | No depictions of violence or gore |
| **Fear / Horror** | No | No frightening content |
| **Sexuality** | YES — Intense / Frequent | Adult dating & social networking (18+) |
| **Nudity** | YES — Mild/Moderate in user content | Public profiles enforce clothed guidelines; adult themes present |
| **Language** | Infrequent / Mild | User-generated conversational text |
| **Controlled Substances**| Infrequent / Mild | Discussion of alcohol, smoking, or night venues |
| **Promotion of Gambling**| No | No real-money gambling |
| **User Interaction** | YES | Users can share location, chat, and exchange media |
| **Shares Location** | YES | Distance and nearby profiles/venues |
| **In-App Purchases** | YES | Auto-renewable subscriptions |

### Resulting Ratings
- **PEGI**: 18 (Adults only)
- **ESRB**: Mature 17+
- **USK**: 18
- **Australia**: R18+
- **Google Play Target Age**: 18+ (Under 18 strictly excluded from target audience)
